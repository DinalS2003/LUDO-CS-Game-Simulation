# LUDO-CS Game Simulation

A complete simulation of the LUDO-CS board game developed in C for the Data Structures and Program Design module at the University of Colombo School of Computing.

## Features
- Full LUDO-CS game simulation
- Four AI-controlled players with unique behaviors
- Clockwise and counter-clockwise movement
- Mystery cell mechanics
- Block creation and captures
- Dynamic game state management
- Console-based gameplay simulation

## Technologies
- C Programming
- Data Structures
- Game Logic Algorithms

## Game Mechanics
The project implements advanced LUDO-CS rules including:
- Mystery cells
- Teleportation mechanics
- Piece blocking
- Direction switching
- AI player strategies
- Capture logic
